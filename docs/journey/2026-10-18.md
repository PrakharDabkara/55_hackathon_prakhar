# 2026-10-18 · Day 15, PR B: optional photos

- **What:** `modules/photos` (magic-byte check, `sharp` re-encode, storage, access rules, limits, sweeper), migration 015, `POST/GET /photos`, photo ids on requests, pings, answers, results and plan items, the errand checklist link, web `PhotoPicker`, `AuthPhoto`, resize and progress, ADR-0030, an e2e with two browsers at 360 px.
- **How:** Tests first, red commits: pure checks (sniff, process with a GPS-tagged fixture), then Postgres integration (access, limits, cap, sweeper, errand item, nothing sent to a model), then the web pieces and the e2e.
- **Why:** The picture is fetched with the login and shown as a `data:` URL, so the CSP stays as it is; the server never trusts the client's resize or type. Rejected: public signed URLs (more surface) and keeping the original (it carries GPS).
- **Learn:** Strip and re-encode at the boundary. A file's name, type and metadata are all claims by the sender; decoding it and writing a fresh one keeps only the pixels.
