## PR: prepare the repo to go public

- **What:** removed private demo numbers from the changelog, runbook and ADR-0062; fixed "two weeks" to "ten days" in `docs/ai-tooling.md`; checked LICENSE, runner fallback and git history for secrets.
- **How:** searched tracked files outside the eval data (the guard hook blocks whole-repo greps); gitleaks in git mode over history only, so the working tree was never scanned; checked every `runs-on` line.
- **Why:** seeds, config and tests still need the private numbers, so they were left alone and listed; ranges like "101 to 110" also implied private numbers, so they became "the reserved demo numbers".
- **Learn:** a numeric range in prose leaks every number in it; grep for the shorthand as well as the full form.

## PR: redeploy latest main

- **What:** LICENSE split into two paragraphs (same terms) and a changelog line.
- **How:** main already had every change from #87 to #89; the push runs for #88 and #89 never started because `ci.yml` has `paths-ignore: ['docs/**', '**/*.md']` and both PRs touched only docs.
- **Why:** deploy is the last job of CI, so a docs-only merge never deploys; LICENSE is not matched by the filter, so this change does.
- **Learn:** "merged but not deployed" after a docs-only PR is the path filter working as designed, not an error.
